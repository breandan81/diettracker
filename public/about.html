About τrend

τrend is a weight trend tracker in the spirit of the Hacker’s Diet: time-aware EMA smoothing, gap-tolerant logging, kcal estimates from slope, and optional Grok coaching.

Renpho BLE auto-log (ESP32)

An ESP32 near your scale can hear a Renpho ES-CS20M / Elis 1 weigh-in over BLE and POST the weight to your account — no phone app tap.

  1. In τrend → Settings, create an ingest token and copy it once.
  2. Download the firmware zip below; copy config.example.h → config.h.
  3. Set WiFi, tracker host/port, and INGEST_TOKEN.
  4. Flash with Arduino IDE / arduino-cli (see README inside the zip).
  5. Fill height / sex / age in Settings so the ESP can push a scale body-fat profile.
Download ESP32 sketch (.zip) Open tracker

Multi-user auth: the ESP sends Authorization: Bearer <ingest-token> on POST /api/weights and GET /api/scale-profile. Tokens are hashed at rest; revoke anytime from Settings.
